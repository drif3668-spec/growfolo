## 3. الهيدر والتنقل

مقاس التابلت (786px) يعرض شريطاً دائرياً عائماً (pill) بدلاً من هيدر كلاسيكي:

```
[أفاتار الحساب] [السلة + شارة عدد] [الإشعارات] [إعدادات المتجر] [الوضع الليلي] ...... [زر القائمة]
```

- شكل كبسولة بيضاء بحواف دائرية كاملة وظل خفيف، مثبتة أعلى الشاشة.
- أيقونات فقط على الجوال (بلا نصوص) لتوفير المساحة.
- **Drawer جانبي** يُفتح بالكامل (Side Navigation Drawer) ويحتوي:
  - بطاقة حساب ("حسابك الشخصي / تسجيل الدخول")
  - قسم "التصفح": الرئيسية، المتجر، المدونة التقنية، تتبع الطلب، الأسئلة الشائعة، حسابي
  - قسم "الخدمات والإعدادات": السلة، مركز الإشعارات، اللغة (عربي/فرنسي/إنجليزي)، العملة (DZD / USD / EUR مع سعر التحويل)، الوضع الليلي/النهاري
  - روابط سوشيال + حقوق النشر + رقم الإصدار `v1.0`

**الدروس القابلة للنقل:**
1. الهيدر يجب أن يحمل **اللغة والعملة والوضع الليلي** كعناصر من الدرجة الأولى.
2. إظهار رقم الإصدار أسفل القائمة يعطي انطباع نظام مُدار.
3. الاختصار إلى أيقونات على الجوال ضروري، لكن يجب إبقاء السلة والحساب ظاهرين دائماً.

## 6. صفحة تفاصيل المنتج (`/product/*`)

### بنية الصفحة (بالترتيب)
1. **H1** — اسم المنتج + لاحقة العلامة (20px، Cairo 900)
2. **التقييم** — زر/شارة `★ 4.9`
3. **اختيار المدة** — أزرار: `0 / 3 / 6 / 9 / 12 شهر (أساسي)`، وكل مدة تُظهر خصمها: "سنة كاملة — بقي 4 — وفّر 43%"
4. **العرض المجاني** — زر "العودة للمجاني 🎁"
5. **السعر** — السعر الحالي بخط كبير (مثال `39,900د.ج`) + السعر القديم مشطوب (`69,800 د.ج`)
6. **إضافة ضمان** — "تمديد الضمان +0 د.ج" (خيار قابل للإضافة)
7. **CTA مزدوج** — "شراء فوري مباشر" (أساسي) + "أضف إلى السلة" (ثانوي)
8. **إجراءات ثانوية** — إضافة للمفضلة، مشاركة المنتج
9. **الميزات** — "الميزات والصلاحيات المضمنة في الحساب"
10. **تقييمات وآراء العملاء** — عرض + نموذج إرسال تقييم
11. **لماذا تختار هذا الاشتراك** — 3 كتل: أصلي وموثوق / تسليم فوري ودعم / ضمان وشفافية
12. **الأسئلة الشائعة** — أكورديون بـ 4 أسئلة جوهرية:
    - كيف يتم التسليم والتفعيل بعد الدفع؟
    - ما طرق الدفع المتوفرة؟
    - الحساب شخصي أم مشترك؟ (يوضّح الفرق بين «حساب شخصي كامل» و«في حسابك الشخصي»)
    - سياسة الضمان وماذا أفعل عند مشكلة؟
13. **منتجات ذات صلة** — 4+ بطاقات
14. **Modal شراء فوري** — "شراء فوري"

### عنوان SEO
```
شراء اشتراك <اسم المنتج> في الجزائر | تفعيل فوري ببريدي موب - AI PLANET
```
نمط قابل للتكيف: `شراء <المنتج> في <السوق> | تفعيل فوري <طريقة دفع محلية> - <العلامة>`

### الدروس القابلة للنقل
- **اختيار المدة كعنصر أساسي** في صفحة المنتج يرفع متوسط قيمة الطلب.
- **السعر القديم + نسبة التوفير** يجب أن يكونا حقيقيين لا decoration.
- **الضمان كخيار قابل للإضافة** فكرة قوية لكن يجب أن تكون له قيمة سعرية واقعية.
- **الأسئلة الشائعة تشرح الفروق الدقيقة** (حساب شخصي vs مشترك) — هذا يقلّل النزاعات بعد الشراء.

## 9. الفوتر

أربعة أعمدة على الديسكتوب، مكدّسة على الجوال:
1. **عن المتجر** — وصف + التقييم `4.9/5 (+500 عميل)` + سوشيال
2. **روابط سريعة** — المتجر، المدونة التقنية، تتبع الطلب، الأسئلة الشائعة، اتصل بنا
3. **الدعم الفني** — بريد + ساعات العمل + وسيلة الدفع
4. **موثوق وآمن** — 3 شارات (تسليم فوري، دفع آمن، دعم سريع) + شعارات الدفع

أسفل الفوتر:
- سطر قانوني: "العلامات التجارية مذكورة على الموقع لأغراض التعريف فقط…"
- روابط: شروط الخدمة · حقوق الملكية الفكرية · سياسة الاسترجاع
- `© 2026 AI PLANET. جميع الحقوق محفوظة.`

**عناصر عائمة:**
- زر **واتساب** بنفسجي بارز أسفل يمين: "تواصل معنا / متصل الآن" + نقطة حالة خضراء.
- زر **العودة للأعلى** دائري بنفسجي أسفل يسار.
- **بطاقة دردشة** منبثقة: "مرحباً بك! هل تحتاج مساعدة في اختيار أو تفعيل اشتراك؟"

**الدروس:**
- زر واتساب بحالة "متصل الآن" يرفع الثقة ويحوّل الزوار إلى محادثة.
- زر العودة للأعلى مهم في صفحات طويلة (المتجر 232 منتجاً).

## 12. ما سنتبنّاه مقابل ما سنتجنّبه

### ✅ سنتبنّاه (كمبدأ، لا كنسخ)
1. هيدر ثابت يحمل السلة/الحساب/اللغة/العملة.
2. Hero بعنوان فائدة واحدة واضحة + CTA واحد أساسي.
3. تسلسل: فئات → كيف تشتري → ثقة → تقييمات → FAQ → نشرة بريدية.
4. صفحة منتج باختيار مدة + سعر قديم حقيقي + CTA مزدوج.
5. FAQ يجيب على أسئلة ما بعد الشراء الحقيقية.
6. تتبع طلب بلا تسجيل دخول إلزامي.
7. زر واتساب عائم بحالة توفر.
8. مقياس خطوط متناسب وتنقّل أيقوني على الجوال.

### ❌ سنتجنّبه
1. نسخ الألوان أو الخطوط أو الشعار أو النصوص.
2. استخدام "3D carousel" كعنصر أساسي (ثقيل على الأجهزة الضعيفة وفي RTL).
3. عرض وسائل دفع غير مفعّلة عندنا.
4. الأرقام التسويقية غير الموثّقة (+500 عميل، 4.9/5) — تُحسب من بيانات Growfolo الحقيقية فقط.
5. الاعتماد على صور بوستر فقط لبطاقة المنتج (ضعيف للـ SEO وللوصولية).
6. العدّادات الوهمية ("بقي 4") إن لم تكن مرتبطة بمخزون حقيقي.
7. الحشو التسويقي الطويل في صفحة المنتج دون بنية قابلة للمسح البصري.

## 13. خطة التكيّف مع Growfolo

### الهوية
| العنصر | Growfolo |
|---|---|
| الاتجاه | RTL عربي كامل |
| الخطوط | عنوان: `Tajawal ExtraBold` أو `Cairo 900` · نص: `Tajawal` / `IBM Plex Sans Arabic` |
| اللون الأساسي | **أخضر-تيل** (نمو + ثقة) بدلاً من البنفسجي — تمييز واضح عن المرجع |
| اللون الثانوي | كحلي داكن `#0B1220` للأسطح الداكنة |
| المحايدات | `#F7F9FC` / `#0F172A` |
| الحواف | 12–16px |
| الأيقونات | `lucide-react` (موجودة في المشروع بالفعل) |

### البنية
- `/` → Hero + فئات + مميز + الأكثر مبيعاً + عروض + ثقة + تقييمات حقيقية + FAQ + نشرة
- `/shop` → فلاتر جانبية + بحث + ترتيب + شبكة بطاقات
- `/product/[slug]` → المعرض + المدة + السعر + الميزات + الشروط + الضمان + FAQ + مشابهة
- `/cart` → إدارة كاملة
- `/checkout` → بيانات + مراجعة + طرق دفع حقيقية + تأكيد
- `/track` → تتبع بلا تسجيل
- `/dashboard` → لوحة العميل
- `/admin` → لوحة الإدارة

### قيود إلزامية
- كل الأسعار والأرقام تُقرأ من قاعدة Neon الحقيقية.
- طرق الدفع من قائمة `orders.payment_method` الفعلية فقط.
- لا صور أو نصوص من الموقع المرجعي.

## 15. الأدلة المستخدمة

| الدليل | الطريقة |
|---|---|
| قيم الألوان والخطوط والمسافات | `getComputedStyle` على عناصر حقيقية |
| بنية الصفحة والأقسام | accessibility tree + قائمة `section` |
| عدد المنتجات والفئات | عدّ العناصر وقراءة عدّادات الأزرار |
| بنية صفحة المنتج | استخراج العناوين والأزرار والسعر من DOM |
| صفحة التتبع | قراءة placeholders الحقول |
| الشكل البصري | لقطات شاشة أثناء الجلسة (الهيدر، الفوتر، شاشة التحميل، بطاقات المنتجات) |

> **ملاحظة:** اللقطات التُقطت أثناء الفحص وعُرضت في الجلسة؛ القياسات الرقمية أعلاه هي المصدر
> الأدق للتنفيذ، لأنها قابلة للتطبيق مباشرة في CSS/Tailwind.
